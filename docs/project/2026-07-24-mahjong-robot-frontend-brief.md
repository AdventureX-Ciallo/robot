# AGILE Mahjong Robot 前端控制台需求稿

> 用途：交给前端同学设计电脑端 UI 控制页面  
> 版本：v0.1  
> 日期：2026-07-24

---

## 1. 前端定位

前端不是宣传官网，而是麻将机器人 Demo 的电脑端控制台。它需要服务三个场景：

1. **研发调试**：查看视觉识别、机械臂状态、串口/网络数据。
2. **现场演示**：一键完成“识牌 -> 算牌 -> 出牌”的演示流程。
3. **宣传展示**：让观众看懂系统正在做什么，为什么机器人要打这张牌。

一句话定位：

> 一个能看见机器人思考、识别和出牌全过程的麻将机器人控制台。

## 3. 页面需求

### 3.1 Dashboard 总览页

目标：让操作者一眼知道系统是否可演示。

模块：

- 系统状态卡片
  - 二哈视觉 2：在线/离线
  - 香橙派：在线/离线
  - GX10/PC：在线/离线
  - PiPER：在线/离线
  - 串口/网络：连接状态
- 当前回合
  - 当前手牌数量
  - 推荐出牌
  - 机械臂动作状态
- 一键操作
  - 开始识别
  - 计算出牌
  - 执行推牌
  - 暂停
  - 急停
- 日志窗口
  - 时间
  - 模块
  - 事件
  - 结果

### 3.2 Vision 视觉识别页

目标：展示二哈视觉 2 / 相机识别效果。

模块：

- 实时画面区域
  - 显示相机画面
  - 叠加麻将牌检测框
  - 显示类别与置信度
- 识别结果表
  - 编号
  - 牌型
  - bbox
  - 置信度
  - 是否为目标牌
- 模型信息
  - 模型名称
  - 模型版本
  - 类别数
  - 推理设备
  - FPS / 延迟
- 操作按钮
  - 截图保存
  - 重新识别
  - 标记误识别
  - 导出样本

### 3.3 Hand State 手牌状态页

目标：让用户看到机器人当前理解的牌局状态。

模块：

- 当前手牌显示
  - 用麻将牌图块展示
  - 支持人工修正牌型
- 可见牌区域
  - 弃牌
  - 副露
  - 已知剩余牌
- 输入模式切换
  - 手动输入
  - 视觉识别
  - 固定槽位
- 状态校验
  - 手牌数量是否正确
  - 是否存在重复超过 4 张
  - 是否有无法识别牌

### 3.4 Decision 决策解释页

目标：展示机器人为什么打这张牌。

模块：

- 推荐出牌
  - 主推荐
  - 替代候选 2-3 张
- 决策指标
  - 当前向听数
  - 打出后向听数
  - 有效进张数
  - 风险评分
  - 综合评分
- 可解释文本
  - “打 3万后仍保持一向听，有效进张最多”
  - “保留两面搭子，舍弃孤张”
- 候选牌对比表
  - 候选牌
  - 牌效分
  - 安全分
  - 综合分

### 3.5 Robot Arm 机械臂控制页

目标：提供安全、可控的 PiPER 操作入口。

模块：

- 机械臂状态
  - 当前关节角
  - 当前末端坐标
  - 当前模式
  - 错误码
- 安全操作
  - 急停
  - 回零
  - 低速模式
  - 回安全位
- 动作控制
  - 移动到目标牌
  - 执行推牌
  - 二次推动
  - 撤离
- 坐标调试
  - 图像坐标
  - 桌面坐标
  - 机械臂坐标
  - 标定偏移

### 3.6 Dataset 训练数据页

目标：辅助团队持续采集和管理训练数据。

模块：

- 样本采集
  - 保存当前帧
  - 保存识别结果
  - 标记误识别
- 数据统计
  - 总图片数
  - 已标注数
  - 各类别样本数
  - 训练/验证集比例
- 模型版本
  - 当前模型
  - 上一版模型
  - 准确率
  - 失败案例数量

### 3.7 Demo Mode 演示模式页

目标：现场演示时只保留最少操作。

流程：

```text
1. 开始识别
2. 确认手牌
3. AI 推荐出牌
4. 机械臂出牌
5. 展示结果
```

页面元素：

- 大画面相机预览
- 当前手牌
- 推荐出牌
- 一句解释
- 机械臂状态
- 大号“开始演示”按钮
- 大号“急停”按钮

## 5. 视觉风格

建议关键词：

- 科技感
- 控制台
- 实验室
- 年轻团队
- 机器人现场演示

建议避免：

- 普通官网首页风格
- 大段营销介绍
- 过度卡片堆叠
- 纯渐变装饰
- 看不见真实画面和数据

主视觉应该优先显示：

- 相机画面
- 麻将牌识别框
- AI 推荐出牌
- 机械臂当前状态

## 6. 接口草案

前端可先按 Mock 数据开发，后续由后端替换。

### 6.1 系统状态

```json
{
  "vision": "online",
  "orange_pi": "online",
  "robot_arm": "online",
  "serial": "connected",
  "emergency_stop": false
}
```

### 6.2 视觉识别结果

```json
{
  "frame_id": "2026-07-24T20:00:00.000Z",
  "tiles": [
    {
      "id": "tile_01",
      "class": "3m",
      "label": "3万",
      "confidence": 0.96,
      "bbox": [120, 240, 60, 90],
      "table_position": [0.21, 0.35],
      "is_target": false
    }
  ]
}
```

### 6.3 决策结果

```json
{
  "recommended_discard": "3m",
  "label": "3万",
  "shanten": 1,
  "ukeire": 18,
  "reason": "打出 3万后保持一向听，并保留更多两面进张。",
  "candidates": [
    { "tile": "3m", "label": "3万", "score": 92 },
    { "tile": "9p", "label": "9筒", "score": 86 }
  ]
}
```

### 6.4 机械臂动作请求

```json
{
  "action": "push_tile",
  "target_tile_id": "tile_01",
  "target_position": [0.21, 0.35],
  "mode": "slow",
  "confirm_required": true
}
```
