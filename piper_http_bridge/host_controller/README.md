# Piper 上位机控制器（Web 面板）

零依赖的上位机控制器：一个 Python 标准库服务，内嵌网页操作面板。
把**夹爪当作有方向的质点**（工具末端点），通过机械臂的 HTTP endpoint 做
笛卡尔点动 + 按轴（关节）点动。浏览器打开即用，键盘/鼠标双操作。

## 启动

前提：机械臂 endpoint 已在运行（香橙派3B 上的 `piper-bridge` 服务，
默认 `http://<香橙派IP>:8080`）。

```bash
# 方式一：脚本
./run_controller.sh --endpoint http://192.168.1.100:8080 --token 你的密钥

# 方式二：直接 python（无任何第三方依赖）
python3 piper_controller.py --endpoint http://192.168.1.100:8080 --token 你的密钥
```

然后浏览器打开 **`http://localhost:8000/`**（或这台上位机的 IP:8000）。

## 键盘操作（焦点在网页上）

| 按键 | 动作 | 按键 | 动作 |
|------|------|------|------|
| `W` / `S` | 前 +X / 后 −X | `X` / `Z` | 滚转 + / − |
| `A` / `D` | 左 +Y / 右 −Y | `C` / `V` | 俯仰 + / − |
| `Q` / `E` | 上 +Z / 下 −Z | `R` / `F` | 偏航 + / − |
| `G` | 合抓 | `H` | 放开 |
| `Space` | ⛔ 急停 | `Enter` | 使能 |

右上角可切换**步长**（小/中/大），面板上的按钮同样可点。

## 高级特性

- **按轴点动**：右侧面板对每个关节 J1–J6 提供 `−` / `+`，单独转动某一轴
  （增量按当前步长）。
- **笛卡尔限幅**：末端 X/Y/Z 有安全范围（`piper_controller.py` 里
  `DEFAULT_LIMITS`），点动到边界自动截停，防止跑出工作空间。
- **实时状态**：关节角、末端位姿、夹爪开度、使能状态、错误码 0.8s 刷新。
- **急停**：Space 或红色按钮，立即恒阻尼停下。

## 安全提示

- 首次使用请把**步长调到「小」**、endpoint 的 `--speed` 调低，确认方向正确。
- 面板默认监听 `0.0.0.0:8000`，同网段都能访问——若不想暴露，用
  `--host 127.0.0.1` 只在本机浏览器开。
- 该面板本身不鉴权，它把 token 转发给 endpoint；token 不落地存储。
